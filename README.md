# OpenPaper 論文館

Dawn's open research-paper line — live at https://openpaper.dawnstudio.app/

Static site (no build step, no trackers). `index.html` is the hall; `papers/` holds one
readable page per paper, rendered from the full texts filed in the Dawn DB (Full-Text Law:
提要 is the admission ticket, never a substitute).

- Founding brief: Dawn workspace `dawn-openpaper-founding.md` (Paper №1 = the auto-grading lifecycle)
- Content Pack v1: 8 curated frontier papers, honestly carded
- Vault shelf: 📄 OpenPaper 論文架 (full texts)
